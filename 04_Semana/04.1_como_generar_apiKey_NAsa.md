Para obtener una clave de API de la NASA, debe registrarse de forma gratuita en el portal oficial de desarrolladores. El proceso es inmediato y **no requiere tarjeta de crédito**.

## Pasos para obtener su NASA API Key

### 1. Entrar al portal de desarrolladores
Visitar el sitio web oficial de **NASA APIs** en [api.nasa.gov](https://api.nasa.gov/).

### 2. Completar el formulario de registro
En la página principal, verás un formulario titulado **"Generate API Key"**. Introduce los siguientes datos:
* **First Name**: Tu nombre.
* **Last Name**: Tu apellido.
* **Email**: El correo electrónico donde recibirás la clave.
* **Application URL**: Este campo es opcional. Puedes dejarlo en blanco o poner tu perfil de GitHub o sitio web.

### 3. Enviar el formulario
Haz clic en el botón **"Signup"**.

### 4. Guardar tu API Key
* La página se recargará y **mostrará tu API Key en la pantalla** de inmediato.
* También recibirás un **correo electrónico de confirmación** con la clave y las instrucciones de uso. Copia esa clave y guárdala en un lugar seguro.

---

## Cómo probar tu clave (Prueba Rápida)

Puedes verificar que tu clave funciona directamente desde tu navegador web:

1. Copia la siguiente URL:
   ```text
   https://api.nasa.gov/planetary/apod?api_key=TU_API_KEY_AQUI
   ```
2. Reemplace `TU_API_KEY_AQUI` por su clave real que genero.
3. Pégala en la barra de direcciones de su navegador y presiona **Enter**.

Si el proceso fue exitoso, verás un archivo de texto en formato JSON con la información y la URL de la **Imagen Astronómica del Día (APOD)**.

---
*Nota: Recuerde mantener su clave en privado para evitar que otros consuman tu límite de peticiones diarias.*
